# Lesson 14 - Metadata

## Experience:

- Metadata is good for SEO, it helps you to setup some configuration regarding your data on the server.
- in Nextjs, there are 2 types of metadata, static and dynamic.
- Static metadata is easy, certain page have static information such as tab title etc.
- Generated metadata you need some steps extra, but more powerful because you wont need manually typing, it will get it directly from params or title
- Metadata is server only, cant do on client side / "use client"
- Beside metadata, you can also setup opengraph image for your social media share purposes.
- Opengraph have 2 types, the static image with jpg or png only, and also dynamic, that can be generated by nextjs `import { ImageResponse } from "next/og";`
- Opengraph image default size is 1200 x 630 px

## Implementation:

- To use metadata, as mentioned above, it has 2 type. Static and dynamic, for static, you can put it inside specific page. with this import and template

```
//static
import type { Metadata } from "next";
export const metadata: Metadata = {
  title: "Lesson 13 - Custom Hooks",
  description: "An online / offline badge from a custom hook.",
};

//dynamic

import type { Metadata } from "next";
export async function generateMetadata({ params }: Props): Promise<Metadata> {
  const { slug } = await params;

  //find posts from data/post
  const post = getPost(slug);

  return post
    ? { title: post.heading, description: post.content }
    : { title: "No data found" };
}


```

- Dynamic are suitable for a dynamic page like blog post, or any page that have live changes.

- To use static OG image, you can easily place a jpg/png image inside src/app folder, it will be the default image to use if you have no other closer og-image.
- To use generated one, you can create an `opengraph-image.tsx` the name is reserved.
- That tsx will automatically build new "social media" image everytime you share a link externally
- dont forget to import the function from here `import { ImageResponse } from "next/og";`
